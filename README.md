# 📸 Instagram Login Page (React)

This project is a **frontend Instagram Login Page UI** built using **React.js**.  
It replicates the look and feel of Instagram’s login screen with a modern, clean, and responsive design.

---

## 📖 Project Description

The Instagram Login Page project is designed to practice **React components**, **UI layout**, and **responsive design**.  
It includes a mobile preview section and a login form similar to the real Instagram interface.

This project focuses only on the **frontend UI** and does not include real authentication.

---

## ✨ Features

- Instagram-style login page UI
- Username or Email input field
- Password input field with show/hide icon
- Login button with gradient effect
- Login with Facebook option
- Mobile app preview mockup
- Responsive layout for different screen sizes
- Clean and modern UI design

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML
- CSS3
- Vite (Development Server)
